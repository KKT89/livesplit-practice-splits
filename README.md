# LiveSplit Practice Splits

LiveSplit のスプリットファイル（`.lss`）から、連続する区間を選んで練習用スプリットファイルを作成します。

## 使い方

ブラウザで `index.html` を開き、元の `.lss` ファイルと開始・終了区間を選んで保存します。インストールやサーバーの起動は不要です。

開始オフセットは 0 に設定します。先頭区間の BEST は空欄にし、以降の BEST は引き継ぎます。累積タイムと走行履歴は引き継ぎません。

保存先の選択に対応するブラウザでは保存ダイアログが開きます。対応しない環境ではダウンロードとなり、保存先はブラウザの設定に従います。

入力ファイルは UTF-8 形式を想定しています。
